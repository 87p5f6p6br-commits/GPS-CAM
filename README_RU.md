# GPS CAMERA — веб-приложение

## Запуск
Приложение должно размещаться на HTTPS-хостинге (например, GitHub Pages, Netlify или Vercel). Камера и геолокация браузера не работают на обычном HTTP-сайте (кроме localhost).

1. Распакуйте архив.
2. Загрузите содержимое папки на HTTPS-хостинг.
3. Откройте адрес сайта в Safari на iPhone.
4. Разрешите доступ к камере и геолокации.
5. Для установки ярлыка: Safari → Поделиться → На экран «Домой».

## Реализовано
- Захват видеопотока камеры через getUserMedia (задняя/передняя камера).
- Высокоточный запрос геолокации: enableHighAccuracy=true, maximumAge=0.
- Отображение фактической точности GPS.
- Получение свежей позиции непосредственно перед снимком.
- Создание оригинала и отдельной копии с GPS-надписью.
- Локальная история IndexedDB, галерея, карта OpenStreetMap при наличии интернета.
- Экспорт/поделиться файлами через системное меню, где поддерживается.
- PWA manifest и Service Worker.

## Важные ограничения Safari
- Браузер не гарантирует заданную точность GPS. Она зависит от устройства, сигнала, разрешений и окружающей среды.
- Веб-приложение не записывает GPS EXIF в исходный JPEG. Координаты хранятся в локальной записи приложения и нанесены на GPS-копию.
- Сохранение в Фото выполняется через системное меню iOS/экспорт, а не прямой записью в медиатеку из JavaScript.
- История хранится локально в Safari. Очистка данных сайта может удалить её; экспортируйте важные снимки.
- Карта требует интернет-соединения. Съёмка и локальное хранение работают офлайн после первой загрузки приложения.
- Для стабильной работы оставляйте страницу открытой во время съёмки.

Это первая рабочая версия (MVP). Перед использованием в качестве доказательства выполнения работ проверьте GPS, экспорт и сохранение на конкретном iPhone.
